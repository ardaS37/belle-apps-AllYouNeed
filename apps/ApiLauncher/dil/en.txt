ApiLauncher 1.3 (formerly ApiLauncher) - chat history and images are stored only on the phone (generated images: E:/Images/ApiLauncher). If a direct connection fails (TLS error) and a server password is set, requests go through the server automatically; photos, image drawing and Grok work in both modes. If Claude refuses for safety reasons, the request is retried automatically on a suitable Claude model.

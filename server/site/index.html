Belle Apps

Nokia E6 (Symbian Belle) için modern uygulamalar · Modern apps for the Nokia E6

Telefondaki BelleAppCenter uygulamaları buradan kurar ve günceller. Elle kurmak için SIS dosyasına dokunun.
BelleAppCenter on the phone installs and updates the apps from here. Tap a SIS file to install it manually.
